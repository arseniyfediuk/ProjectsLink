# ProjectsLink

A collection of my electronics and software engineering projects.

1\. \[Huawei STC 2026 – Digital Energy]

A hybrid digital energy system (solar panels, gas CHP generator, and battery storage) developed for the Huawei Student Tech Conference 2026. Includes the technical architecture overview and English pitching materials that took our 3-member engineering team to the national semifinals in Kyiv.



2\. \[AC Zero-Cross Detector]

Hardware design, calculation, and documentation for a solid-state AC power-switching device. This project features a zero-crossing detector using PC814 optocouplers to safely monitor 230V/50Hz mains and generate precise synchronization pulses for microcontroller phase control. Includes circuit calculations, EasyEDA PCB routing, and real oscilloscope test results.



3\. \[KiCad Laboratory Works]

A collection of educational PCB design projects completed during my university studies. Demonstrates the full hardware development cycle: schematic capture (Eeschema), manual topological trace routing (Pcbnew), DRC/ERC checks, component specification, and 3D board visualization.
